# Preferências do proprietário

- Alterações no código e testes não autorizam gerar uma nova versão, executar o compilador do instalador ou publicar uma atualização. Faça isso somente quando o proprietário pedir explicitamente uma nova versão ou atualização para distribuição.
- Há autorização para aplicar correções na instalação deste computador. Preserve contas, livros, progresso e preferências; não altere o número da versão publicada durante manutenção local.
- Táticos e Aberturas devem funcionar integralmente offline com os recursos incluídos no aplicativo. Nenhum desses treinos deve depender da API de táticos, de baixar material ao abrir ou da disponibilidade do painel central.
- Nunca inclua contas, bancos particulares, credenciais do criador ou senhas no instalador, no código ou no pacote do servidor.
- Explique separadamente integração implementada e serviço efetivamente publicado. Não afirme que há hospedagem pública ou lista global ativa antes de existir um servidor HTTPS configurado.
