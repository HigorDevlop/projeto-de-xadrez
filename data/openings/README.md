# Catálogo de aberturas

Arquivos `a.tsv` a `e.tsv` de [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings), obtidos em 15/09/2026. Licença CC0; texto original em `COPYING.txt`.

O aplicativo indexa os pares posição/lance de cada linha PGN e inclui essas entradas automaticamente. A identificação é feita pela posição, incluindo lado a jogar, direitos de roque e en passant, permitindo transposições. Os PGNs e livros Polyglot carregados pelo usuário complementam o catálogo. Este não é o banco de aberturas privado do Chess.com.
